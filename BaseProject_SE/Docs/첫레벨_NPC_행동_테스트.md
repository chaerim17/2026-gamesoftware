# 첫 레벨: 이야기 기반 자율 NPC 10명

통합_게임_기획서.md 6.3~6.6의 성격·욕구·관계·기억·능력·목표와 독립적인 행동·죽음을 첫 사냥터에서 시험한다. 본편 인물과 결말을 확정하는 문서가 아니다.

| NPC | 이야기와 행동 |
|---|---|
| 이동 상인 마로 | 전쟁으로 끊긴 교역로에서 난민에게 식량을 팔고 수익을 확보한다. 위험한 사람과 거래하지 않는다. |
| 성직자 엘라 | 전쟁의 편을 묻지 않고 부상자를 찾아 약초로 치료한다. 약초는 소비되며 무제한 치료하지 않는다. |
| 경비 아델 | 주민을 호위하고 인근 맹수를 제압한다. 민간인 공격을 직접 목격하면 가해자에 대응한다. |
| 사냥꾼 라크 | 계곡의 현재 안전을 확신하지 못한다. 흔적을 조사하고 맹수를 사냥해 식량을 얻는다. |
| 동료 전사 타렌 | 피난민을 지킨 책임감으로 주민을 호위하고 위험한 길을 정찰한다. 피해를 목격하면 싸운다. |
| 난민 대표 나린 | 전승보다 당장 먹을 식량을 우선한다. 상인을 찾아 물자를 구매한다. |
| 레나 | 귀환한 주인공을 기다렸지만 가족이 먼저 떠났다. 상인·사냥꾼·협상자에게 이동해 행방을 묻고 전언을 모은다. |
| 협상자 세온 | 계곡 외에도 생존의 대안을 찾는다. 물자를 구매하고 만난 인물과 정보를 교환한다. |
| 패잔병 도란 | 전쟁 뒤 생계와 소속을 찾는다. 상인·난민을 호위하고 인근 위협에 대응한다. |
| 산적 가르 | 교역로에서 상인을 추적해 대금을 약탈하고 공격한다. 크게 다치면 도주한다. |

## 전투와 결과
- 기존 Space/왼쪽 클릭 공격 판정을 모든 첫 레벨 NPC에도 적용한다. 공격 방향·거리·지형 시야를 확인하며, 캠프에서도 NPC PK가 가능하다.
- 공격받은 전투 NPC는 보복하고 비전투 NPC는 도주한다. 관계가 나빠지면 서비스와 거래를 거절한다.
- NPC끼리 공격·방어·치료·거래가 발생한다. 모든 NPC가 사망 가능하며 죽으면 행동과 상호작용이 중단된다. 별도 진행 필수 NPC는 없다.
- NPC 처치는 경험치를 주지 않는다. NPC가 사냥한 몹의 보상도 플레이어에게 자동 귀속하지 않는다.
- 현재 실행의 사망·관계는 유지한다. 새 맵/게임 재실행 시 NPC를 다시 배치한다. NPC 상태의 파일 저장은 아직 포함하지 않는다.
- 인벤토리 교환 및 플레이어 성장 정보는 기존 저장을 이용한다. NPC 거래의 돈과 식량은 실행 중 시뮬레이션용 상태다.

## 정보와 JSON
- 실제 사건은 최근 64개 기록: attack, death, beast_attack, hunt, robbery, trade, heal, inquiry.
- 8월드 단위 이내이며 지형 시야가 열린 생존 인물만 직접 목격 기억을 얻는다. 가까이 만난 사람은 최신 기억을 전언으로 공유한다.
- 세계 사건과 NPC의 최근 기억은 별도다. 범인 정보가 전역 평판으로 자동 전달되지 않는다. 기억은 최근 사건 1개이며 출처와 원 사건 시각을 유지한다.
- NPC JSON: id/name/role/personality/goal/state/reason/alive/health/supplies/coins/hunger/x/y/target_x/target_y/target_npc_id/target_enemy_id/relations/known_event_id/memory/knowledge_source/knowledge_time_seconds.
- events JSON: id/time_seconds/type/actor_id/target_id/text/x/y. player는 플레이어, level_one_npc_N은 NPC, null은 특정 NPC로 식별하지 않는 사냥·맹수 사건이다.
- 모니터에 행동 이유·상태·체력·물자·기억과 출처·최근 실제 사건을 표시한다. 전체 세부 상태는 수신 JSON에서도 확인 가능하다.
- 캠프 인구는 생존 NPC에서 산적을 제외한다. NPC 수는 사망자를 포함하는 등록 수다.
- 게임 창이 비활성일 때 입력은 비우고 시뮬레이션은 계속한다. 기존 메뉴/일시정지/플레이어 사망 상태에서는 진행을 멈춘다.

## 수동 확인
게임을 재빌드하고 튜토리얼을 완료하거나 `--level-one`으로 직접 실행한다. 모니터에서 10명과 캠프 인구 9명을 확인한다. 치료·거래·산적 공격을 관찰하고 NPC를 공격해 관계 하락·보복·도주·사망을 확인한다. 죽은 NPC는 E 대상에서 제외되고 목격/전언 출처가 구분되어야 한다.

서식, 프로젝트 등록, JavaScript 문법 및 소스 정적 검토만 수행했다. 빌드·실행·전투 균형은 미검증이다. 본편의 정착 선택·장기 계약·전역 NPC 저장·복잡한 기억 및 관계망은 이번 테스트 구현 범위에 포함하지 않는다.
