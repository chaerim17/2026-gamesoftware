# 잿골 마을 자율 NPC 테스트

이번 구현은 통합_게임_기획서.md 6.3~6.9를 작은 마을에서 검증하는 시제품이다. 제안된 본편 인물을 확정하지 않으며, 직업·성격·욕구·능력·목표·관계·최근 기억을 사용한다.

## 실행 및 규모
- 기본 실행 및 `--tutorial`은 안내 NPC 6명으로 시작하며, 북쪽 관문에서 E로 완료하면 첫 사냥터로 자동 전환한다. 38명 마을 테스트는 `--village`, 사냥터 직접 실행은 `--level-one`.
- NPC는 18명 + 20명 = 38명. 추가한 20명 중 기획서 6.9 후보 패턴 10명은 주요 자율 NPC로 표시한다.
- 등록 주민 35명과 산적 3명. 모니터 인구는 생존 주민만 계산한다.
- 이동 영역 x[-34,34], y[-34,28] → x[-68,68], y[-68,56]. 가로·세로 2배, 면적 4배.
- 동물은 기존 14마리 + 96마리 = 110마리. 사슴 26마리, 전투 몹(멧돼지·늑대) 84마리. 처치 후 35초에 재생성한다.
- 초기 배치는 플레이어 시작점에서 도달 가능한 지형에 보정한다. NPC 경로도 해당 연결 구역만 이용한다.
- WASD 이동 / E 대화 / F 근거리 공격 / Esc 일시정지 / Tab 지도 / P 후처리.
- 게임 창을 비활성화하면 입력은 지우고 마을 시뮬레이션은 계속한다. Esc 일시정지 상태는 유지한다.

## 행동
| 직업·패턴 | 실제 시험 행동 |
|---|---|
| 공동체 지도자·가족 탐색자·중재자 | 사람에게 이동해 최신 전언을 수집·전달 |
| 경비·동료 전사·패잔병 | 순찰, 인근 맹수 대응, 산적 추적·제압 |
| 사냥꾼 | 위험 대응·사냥, 사냥 시 물자 획득 |
| 상인·협상자·난민 대표 | 거래 상대를 찾아 이동, 돈과 물자 교환 |
| 경작자·장인 | 생활 이동 및 물자 생산 |
| 성직자 | 다친 주민을 찾아 치료, 인근 플레이어도 치료 |
| 선량한 주민 | 부족한 이웃에게 음식 제공 |
| 산적 | 상인을 추적해 돈을 빼앗고 피해를 가함 |
| 악한 주민 | 일반 가격보다 비싸게 판매 |

몸 상태와 주변 위험이 우선한다. 비전투 인물은 맹수를 피하고, 관계가 나쁜 인물과 거래를 피한다. 플레이어에게 공격당한 전투 인물은 보복하고 비전투 인물은 도주한다. 사망한 NPC는 이동·거래·치료를 멈춘다. NPC 사망은 이 실행 중 유지되며 부활하지 않는다.

## 사건·모니터
- 공격·사냥·약탈·거래·치료·나눔을 실제 사건으로 기록한다(최근 32개).
- 사건의 7월드 단위 이내 인물에게만 직접 목격 기억을 부여한다.
- 가까이 접촉한 NPC는 최신 사건을 전언으로 공유하며 출처·원 사건 시각을 남긴다. 월드 사실을 자동으로 전원에게 전달하지 않는다.
- 모니터에 직업·성격·목표·욕구·체력·물자·최근 기억과 출처, 실제 사건 목록을 표시한다. 능력·관계·주요 인물 여부는 원본 JSON에서도 확인할 수 있다.
- 분위기는 생존 NPC의 도주·부상 상태를 기준으로 계산한다. 소문은 현재 NPC가 전언으로 알고 있는 내용이다. 성향 집계는 직업의 시험 분류이며 본편 평판 시스템이 아니다.

## 제한 및 수동 확인
- 본편의 가족 재회·정착 협상·고용 계약·전역 평판·전체 월드 스트리밍까지 구현한 것은 아니다.
- 일반 관계는 인물별 신뢰 증감, 기억은 최근 사건 1개다. 지도 전체 상시 시뮬레이션은 현재 마을에 한한다.
- 장로·정찰병(기존 튜토리얼 0/1번)은 진행 보호를 위해 원래 위치를 유지하고 공격 대상에서 제외한다. 나머지 인물은 사망 가능하다. 시작 광장 주변 12단위는 몹의 공격 대상에서 제외한다.
- NPC 상태·마을 사건은 실행 간 저장하지 않는다. 다시 실행하거나 완료 후 R로 초기화한다. 기존 사냥터 성장 저장은 별개다.
- 서식·등록·정적 검토만 수행했다. 빌드·실행·실제 경로 이동·전투 균형은 사용자가 확인한다.
- 확인 순서: 모니터 38명/84몹/26야생동물 → 1분간 거래·치료·산적 충돌 → F 처치·35초 재생성 → NPC 기억/전언 출처 → 지도 외곽과 호수 우회 → Esc 시뮬레이션 정지.
