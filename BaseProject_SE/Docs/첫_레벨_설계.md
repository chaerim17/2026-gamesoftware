# 첫 레벨 — 사냥꾼의 첫걸음

## 목적과 범위

기존 마을 튜토리얼 다음에 사용할 전투·성장 프로토타입이다. 숲과 호수가 있는 무작위 사냥터에서 검으로 멧돼지와 늑대를 사냥하고, 전리품과 경험치를 얻어 능력치 배분까지 경험한다. 세계관의 핵심 줄거리를 확정하는 레벨은 아니다.

기본 실행은 첫 사냥터다. 실행 인자 `--tutorial`을 전달하면 기존 마을 튜토리얼을 연다. 두 레벨 사이의 자동 이동은 아직 연결하지 않았다. 기존 튜토리얼의 5분 이내 목표는 유지하며, 이번 사냥터는 시간 제한 없이 반복 사냥할 수 있다.

## 플레이 흐름

1. 중앙 캠프에서 시작한다. 주변 보급 상자에서 약초와 가죽을 획득할 수 있다.
2. 지도를 보고 숲으로 이동해 멧돼지·늑대를 사냥한다.
3. 처치 시 경험치를 즉시 얻고, 바닥의 전리품은 E로 획득한다.
4. 캐릭터 레벨이 오르면 기본 능력치와 성장 포인트가 증가한다.
5. C를 눌러 힘·체력·방어에 포인트를 배분한다.
6. **레벨 3 이상, 성장 포인트 누적 6개 이상 배분, 아이템 획득 1회 이상**을 달성한 뒤 캠프에서 E를 누르면 완료 화면을 표시한다.

완료 후 같은 사냥터에서 계속 사냥하거나 새 사냥터를 생성할 수 있다. 완료 조건과 아래 수치는 이번 프로토타입의 조정 가능한 초기값이다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 화면 방향 기준 이동, 대각선 이동 속도 정규화 |
| 마우스 왼쪽 클릭 | 클릭한 방향으로 검 공격 |
| Space | 바라보는 방향으로 공격, 누르고 있으면 반복 |
| E | 가까운 전리품 획득, 캠프 회복 또는 레벨 완료 |
| F | 약초 1개로 생명력 최대 35 회복, 가방에서도 사용 가능 |
| C | 능력치 창 열기·닫기 |
| 능력치 창의 1 / 2 / 3 | 힘 / 체력 / 방어에 1포인트 배분 |
| I / H | 가방 / 도움말 열기·닫기 |
| Tab / P | 지도 표시 / 후처리 전환 |
| Esc | 창 닫기 또는 일시정지·재개 |
| 일시정지·완료 화면의 N | 생존 중 새 사냥터 생성, 성장과 가방 유지 |
| 일시정지·완료 화면의 Q | 진행 저장 후 종료 |
| 사망 화면의 R | 캠프에서 부활, 경험치·능력치·아이템 유지 |

메뉴를 열거나 창이 포커스를 잃으면 진행을 멈춘다. 캠프 반경 4 안에서는 짐승이 추적·공격하지 않으며, 캠프 반경 2 안에서 E로 완전히 회복할 수 있다.

## 전투와 전리품

검은 약 135도 전방 부채꼴, 거리 2.2 이내를 공격한다. 공격 간격은 0.55초, 타격 판정은 공격 시작 0.12초 후 1회다. 공격 초반에는 이동 속도가 줄어든다. 지형 너머의 적에게는 피해를 주지 않는다.

| 종류 | 배치 목표 | 생명력 | 공격력 | 방어력 | 처치 경험치 |
|---|---:|---:|---:|---:|---:|
| 멧돼지 | 12 | 42 | 11 | 1 | 35 |
| 회색늑대 | 6 | 56 | 15 | 2 | 55 |

받는 피해는 공격력에서 방어력을 뺀 값이며 최소 1이다. 플레이어가 피격된 뒤 0.5초 동안 추가 피해를 막는다. 적은 플레이어까지의 지형 경로를 따라 추적한다.

처치 시 약초 또는 가죽 1개가 떨어진다. 약초 확률은 1/3이다. 전리품은 실제 처치 위치에 남으며 거리 1.6 이내에서 E로 줍는다. 가죽은 이 단계에서는 수집 재료이고 판매·제작 기능은 없다. 장비 교체와 활 전투는 이번 범위에 포함하지 않는다.

적은 처치 후 20초가 지나고 플레이어가 최초 배치 위치에서 6 이상 떨어져 있으면 재등장한다. 미수거 전리품이 100개 이상이면 재등장을 보류한다. 이미 활동 중인 적의 전리품은 버리지 않는다.

## 경험치와 능력치

초기 능력치는 생명력 100, 공격력 18, 방어력 3이다. 초기 약초는 3개다.

| 캐릭터 레벨 | 필요한 누적 경험치 | 자동 증가 적용 후 생명력 / 공격 / 방어 | 누적 성장 포인트 |
|---|---:|---|---:|
| 1 | 0 | 100 / 18 / 3 | 0 |
| 2 | 100 | 120 / 22 / 4 | 3 |
| 3 | 250 | 140 / 26 / 5 | 6 |

레벨 L에서 다음 레벨까지 필요한 경험치는 `100 + 50 × (L - 1)`이다. 레벨 상승마다 생명력 +20, 공격력 +4, 방어력 +1, 성장 포인트 +3을 얻는다. 상승으로 늘어난 최대 생명력만큼 현재 생명력도 증가한다.

| 배분 능력치 | 1포인트 효과 |
|---|---|
| 힘 | 공격력 +2 |
| 체력 | 최대·현재 생명력 +10 |
| 방어 | 방어력 +1 |

남은 포인트가 없으면 배분하지 않는다. 포인트 되돌리기는 제공하지 않는다. 캐릭터는 50레벨까지 성장할 수 있으며, 첫 레벨 완료는 캐릭터 3레벨부터 가능하다.

## 무작위 맵과 접근성

- 크기는 64×60 타일이다. 실행하거나 새 사냥터를 선택하면 새 난수 시드로 지형과 적 배치가 바뀐다.
- 풀·흙은 이동 지형, 물·나무·바위·외곽은 장애물이다. 중앙 캠프 주변 9×9 구역을 확보한다.
- 캠프에서 상하좌우 탐색을 수행하고, 도달하지 못하는 땅이 있으면 흙 통로로 연결한다. 모든 이동 지형이 연결될 때까지 반복한다. 물이나 장애물 위를 걸을 수 있다는 의미는 아니다.
- 캐릭터 충돌 폭은 0.44타일이다. 한 칸 통로에서도 이동할 수 있도록 타일 연결성·충돌 크기를 맞췄다.
- 적은 연결된 이동 지형의 중심에 배치하며 캠프에서 7 이상 떨어진 위치를 사용한다. 떨어뜨린 아이템도 이동 가능한 적의 위치에 생성된다.
- 이동·시야·공격·아이템 획득은 동일한 지형 판정을 사용한다. 적의 경로장은 0.2초마다 갱신한다.
- 디버그 실행에서는 생성 직후 연결성을 단언문으로 확인한다. 실제 다양한 시드의 이동·추적 결과는 사용자 실행으로 확인해야 한다.

## 모델 캐시와 셰이더

외부 모델링 도구 없이 삼각형·사각형·타원으로 캐릭터, 나무, 바위, 짐승, 집, 상자, 모닥불을 구성한다. 기존 나무와 집의 세부 도형을 공용 모델로 옮겼다.

실행 파일이 있는 폴더 아래 `GameData`에 다음 파일을 생성한다.

| 파일 | 내용 | 다음 실행 |
|---|---|---|
| `models.cache` | 8종 모델의 지역 좌표·색·UV·재질을 담은 정점 데이터 | 도형 재생성 없이 불러와 위치·크기·가림·걸음 변형 적용 |
| `characters.cache` | 외형 6종×방향 4종×걷기 8프레임, 1536×768 RGBA 아틀라스 | 아틀라스 재생성 없이 파일을 GPU 텍스처로 업로드 |
| `progress.save` | 경험치, 배분 능력치, 약초, 가죽, 처치·획득 누적 수 | 캐릭터 성장 이어하기 |

캐시가 없거나 버전·길이·체크섬이 맞지 않으면 해당 자산만 재생성한다. 정점 캐시는 정점 개수와 유효한 실수·재질 범위도 확인한다. 모델 생성 방식이나 아틀라스 구성을 바꾸면 해당 캐시 버전을 올린다. 한글 글꼴은 실행 중 필요한 글자를 기존 방식으로 만든다.

불꽃 형태·연기·불티는 정적인 사각형 위에서 시간 유니폼을 받는 셰이더로 움직인다. 물결과 반사광도 물 재질 셰이더가 처리한다. 모닥불의 돌·장작은 캐시 모델을 재사용한다. 지형 재질, 그림자, 후처리 기능은 기존 렌더러를 사용한다.

## 진행 저장

처치, 획득, 능력치 배분, 약초 사용, 캠프 휴식, 일시정지, 새 사냥터 이동 전, 정상 종료 시 진행을 저장한다. 임시 파일을 기록한 다음 대상 파일을 교체한다. 저장 실패 시 화면에 안내한다.

맵·바닥 전리품·적의 상태·현재 생명력은 저장하지 않는다. 다음 실행에서는 성장과 가방을 복원하고 새 맵의 캠프에서 최대 생명력으로 시작한다. 새 사냥터를 생성해도 성장과 가방은 유지한다. 저장 데이터가 없거나 유효하지 않으면 초기 능력치로 시작한다.

처음부터 다시 확인하려면 게임 종료 후 `progress.save`를 다른 위치로 옮긴다. 모델 캐시만 다시 확인하려면 진행 파일은 남겨 두고 두 캐시 파일만 다른 위치로 옮긴다. 실행 구성에 따라 실행 파일 폴더가 다르므로 Debug·Release의 진행 파일도 따로 생성된다.

## 코드 구성

| 파일 | 역할 |
|---|---|
| `SimpleGame.cpp` | 기본 레벨 선택, 키·마우스 입력, 포커스와 종료 처리 |
| `LevelOne.h/.cpp` | 첫 레벨 진행, 공격·적 행동·전리품·메뉴 입력 |
| `LevelOneRender.cpp` | 사냥터, 지도, 한글 HUD와 능력치·가방 창 |
| `LevelMap.h/.cpp` | 무작위 지형, 연결성 보정, 충돌, 경로장 |
| `PlayerProgress.h/.cpp` | 경험치·능력치 수식, 포인트, 가방과 진행 저장 |
| `GameStorage.h/.cpp` | 캐시·진행 파일 읽기·쓰기, 버전·체크섬 검사 |
| `RendererModels.cpp` | 정적 도형 모델 생성·캐시·배치, 불꽃 사각형 |
| `RendererAssets.cpp` | 캐릭터 아틀라스 캐시, 기존 한글 글꼴 처리 |
| `Renderer.cpp/.h` | 공용 렌더링과 물·불 셰이더, 화면 좌표 변환 |
| `TutorialWorld.cpp` | 기존 튜토리얼에서 공용 모델·불꽃 재사용 |

코드는 `.clang-format`과 `.editorconfig`를 따른다. Allman 중괄호, 공백 4칸, 처리 단계 사이의 빈 줄을 유지한다. 새 파일을 프로젝트와 필터에 등록하고 네 빌드 구성의 한글 소스 옵션과 `NOMINMAX`를 사용한다.

## 사용자 확인 항목

빌드·게임 실행·렌더링 결과는 이번 작업에서 수행하지 않는다. 아래 항목은 구현 사실과 구분되는 수동 확인 대상이다.

1. 기본 실행과 `--tutorial` 실행이 각각 열리고 한글 UI가 읽히는지 확인한다.
2. WASD, 클릭·Space 공격, 지형 충돌, 적의 추적·피격·사망을 확인한다.
3. 처치 경험치가 한 번만 지급되고 E로 약초·가죽을 획득하는지 확인한다.
4. 경험치 100·250에서 레벨이 오르고, C의 1·2·3 배분이 능력치에 반영되는지 확인한다.
5. 아이템 획득·레벨 3·포인트 6개 배분 후 캠프의 완료 동작을 확인한다.
6. 죽은 뒤 R로 부활하고, 창 포커스 전환이나 메뉴 종료 뒤 입력이 붙잡히지 않는지 확인한다.
7. 새 사냥터를 여러 번 생성해 통로 이동·적 추적·전리품 접근을 확인한다.
8. 첫 실행의 캐시 생성 후 재실행 시 콘솔에 캐시 불러오기 메시지가 뜨는지 확인한다. 종료·재실행 뒤 성장과 가방도 확인한다.
9. 창 크기를 바꾸어 클릭 방향을 확인하고, 물결·불꽃·연기·불티·그림자와 P 후처리 차이를 확인한다.
