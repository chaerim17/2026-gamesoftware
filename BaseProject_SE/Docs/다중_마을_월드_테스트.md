# 다중 마을 월드 테스트

통합_게임_기획서.md의 폐허 조사 → 피난 추적·교역·경로 선택 → 계곡 기존 주민과의 만남을 한 지도에서 시험하는 배치다. 상세 지명은 미정이므로 길목 교역마을/갈림길 정착지는 임시 이름이며, 본편 최종 지리·정착 결말을 확정하지 않는다.

## 월드 배치
지도는 512×480 셀이다(직전 128×120 대비 가로·세로 4배, 면적 16배). 장면 로딩 없이 걸어서 이동한다. 5개 거점은 넓은 광장과 3셀 폭 도로로 연결하며, 기존 연결성 보정을 유지한다.

| 지도 번호 | 거점 | 좌표 | 역할 | 초기 소속 NPC |
|---|---|---|---|---|
| 1 | 불씨 피난민 캠프 | (-100.5, 82.5) | 불씨·회복·전언 | 성직자 엘라, 협상자 세온 |
| 2 | 옛 고향의 폐허 | (-204.5, 168.5) | 가족·피난 흔적 조사 | 사냥꾼 라크, 레나 |
| 3 | 길목 교역마을 (임시) | (-12.5, -2.5) | 교역·호위·산적 위협 | 상인 마로, 경비 아델 |
| 4 | 갈림길 정착지 (임시) | (110.5, 56.5) | 다른 피난 집단과 물자 교섭 | 동료 전사 타렌, 난민 나린 |
| 5 | 첫 불의 계곡 주민 마을 | (206.5, -180.5) | 기존 주민의 터전·정착 갈등 | 터전지기 하단 |

산적 가르는 거점 밖에서 시작한다. 총 NPC 수는 이전 요구대로 10명을 유지한다. 하단은 기존 패잔병 후보 슬롯을 계곡 주민 패턴으로 바꾼 테스트 인물이다. 숫자는 전체 실제 마을 주민 수를 뜻하지 않고 이번 시뮬레이션에 등록된 NPC 수다.

각 거점에 건물/폐허 도형 4개를 배치하며 지형 충돌에도 반영한다. 지도에 번호·거점 표식, 월드에 이름, HUD에 현재 지역을 표시한다. 건물은 실내 진입을 지원하지 않는다.

## NPC와 위험
- 소속 NPC를 마을에 나누고, 상인·협상자·가족 탐색자의 교류와 탐색이 마을 사이 이동으로 이어진다.
- 소속(home affiliation)과 현재 위치(current village)를 구분한다. 이동했다고 바로 다른 마을 주민으로 편입하지 않는다.
- 계곡 주민은 자신의 거점에서 생활·방어하고 공격받으면 기존 PK 규칙대로 반응한다.
- 맹수는 거점 광장 밖에 최대 320마리 배치한다. 사냥·재생성 및 NPC 간 전투를 유지한다.
- 이전의 첫 레벨 성장 완료 조건과 캠프 회복·부활은 유지한다. 계곡 최종 협상/정착 퀘스트는 아직 구현하지 않았다.

## JSON 모니터
- villages 배열에 5개 거점을 개별 기록한다: id/name/purpose/x/y/ruined/population/present_npcs/mood/alignment/rumors.
- population은 해당 거점 소속 생존 NPC 수이며 폐허의 조사 인물도 등록 소속으로 집계한다. present_npcs는 현재 경계 안에 있는 생존 NPC 수로 방문객과 산적도 포함한다.
- 분위기는 현장 부상·적대 대응·산적 유무, 소문은 현장 인물의 전언으로 계산한다. alignment는 현재 지역의 기획 역할이다(별도의 정치 성향 시뮬레이션이 아니다).
- NPC의 village_id는 소속, current_village_id는 현재 위치다. 야생에서는 null이다.
- world_width/world_height는 지도 크기다. 기존 행동/관계/사건 JSON도 유지한다.

## 확인
게임을 빌드한 뒤 기본 실행으로 월드에 들어간다(튜토리얼 시작은 현재 비활성). 지도 1~5번 거점·도로·건물 충돌, 모니터의 거점별 인구, NPC 거점 사이 이동 및 소속/현재 위치 구분, PK 사건과 해당 지역 분위기를 확인한다.

빌드·실행은 하지 않았다. 코드 서식·XML/JavaScript 문법·정적 좌표/구조 확인만 수행했다. 거점의 정밀 아트·풍부한 배경 인구·월드 상태의 영구 저장·본편 전체 퀘스트는 후속 범위다.

## 현재 시작·저장 설정 (2026-10-14)
- 첫 월드의 고향 폐허에서 바로 시작한다. 거점 순서는 고향 폐허 → 불씨 피난민 캠프 → 교역마을 → 다른 피난민 정착지 → 첫 불의 계곡이다. 직선 거점 간 최소 간격은 약 122월드 단위이며 실제 도로 이동은 더 길다.
- 튜토리얼 시작 분기와 --tutorial/--village 활성화는 SimpleGame.cpp에서 주석 처리했다. 완성 단계에서 해당 TODO와 분기를 복구한다. 기존 튜토리얼 코드는 보존한다.
- 성장 정보 저장·불러오기 호출과 PlayerProgress::Save/Load의 파일 구현을 주석 처리했다. 실행마다 기본 스탯·경험치·인벤토리로 시작하며 현재 실행의 성장은 가능하다. 기존 progress.save는 삭제하지 않으며 사용하지 않는다. 모델 캐시와 JSON 모니터 파일은 유지한다.
- 커진 경로 필드는 vector로 관리해 큰 임시 배열의 스택 사용을 피하고, 지면은 카메라 주변, 미니맵은 축약 샘플로 표시한다. 같은 목표 셀은 경로를 재계산하지 않는다.
- 지형·도로·거점 배치와 NPC 이동은 테스트 구현이다. 본편 전체 서사 퀘스트와 최종 지리의 확정은 아니다. 빌드·실행은 미검증이다.
