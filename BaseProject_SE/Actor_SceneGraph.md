# Actor / SceneGraph

Actor는 배치 객체의 이름·위치·부모·자식·활성·표시 상태와 그리기/그림자/갱신 콜백을 가진다. SceneGraph는 Actor를 소유하고 등록·검색·삭제·부모 변경과 렌더 패스 순회를 담당한다.

- 사냥터: 지면 타일, 나무·바위, 적, 플레이어, 캠프와 자식 불꽃, 전리품, 검 효과, 피해 숫자, HUD·패널.
- 튜토리얼: 지형 묶음, 집, 나무, NPC, 짐승, 플레이어, 캠프와 자식 불꽃, 단서, 출구, 표식, 꽃가루 효과, HUD.
- 객체를 구성하는 모델 정점·글자·UI 장식은 해당 Actor 안에서 함께 그린다.

```cpp
Actor& camp = scene.Create("camp");
camp.SetPosition({2, 3});
Actor& fire = scene.Create("fire", &camp);
fire.SetLocalPosition({0, 0});
camp.SetVisible(false); // 자식도 숨김
camp.SetPosition({5, 3}); // 자식 위치도 이동
scene.Reparent(fire, nullptr); // 월드 위치 유지, 순환/다른 그래프의 부모 거부
scene.Destroy(&camp); // 남아 있는 자식도 함께 제거
```

기존 위치는 BindPosition으로 직접 연결하여 Actor 이동을 게임 데이터에 반영한다. 기존 이동 코드의 변경도 그래프 순회 전에 동기화한다. 바인딩한 위치의 주소를 바꾸거나 지우기 전에 해당 Actor를 제거해야 한다. 아이템과 피해 숫자는 list에 보관하여 다른 항목 생성·삭제로 주소가 바뀌지 않도록 했다. 레벨 재생성은 그래프를 먼저 비운다.

위치 이동과 활성·표시 상태는 자식에 적용된다. 회전·크기 변환은 아직 계층 변환에 포함하지 않는다. 타일 충돌은 기존 LevelMap의 고정 격자를 유지한다. 지형을 재배치하려면 충돌 데이터도 함께 수정해야 한다. AI의 배회 기준점(home) 역시 위치와 별개인 게임 데이터다.

소유권 변경은 순회 콜백 바깥에서 수행한다. 순회 중 변경은 참조 무효화를 막기 위해 예외로 거부한다. 활성화는 갱신·그리기를, 표시 여부는 그리기만 제어한다. 기존 전투/이동 로직은 레벨 컨트롤러에 유지하며 적·NPC·짐승의 활성 상태를 확인한다.

렌더 순서는 지면 → 그림자 → 깊이순 월드 → 효과 → 후처리 → UI다. 같은 깊이는 등록 순서를 유지한다. 새 객체 등록은 LevelOneScene.cpp, TutorialScene.cpp를 참고한다.

정적 확인: 프로젝트 등록, 서식, 생성·삭제 시 참조 수명과 순회 경로. 빌드·실행은 사용자 확인 대상이다. 기존 두 레벨의 플레이, 아이템 생성/획득, 팝업 소멸, 새 맵·튜토리얼 초기화, 부모 표시/이동/재연결을 확인한다.
