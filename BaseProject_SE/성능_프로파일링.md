# 성능 프로파일링

## 적용 내용
- 공통 도형을 인스턴싱하고 모델 아틀라스를 파일 캐시와 GPU에서 재사용한다.
- SceneGraph의 렌더 큐를 재사용하고 공간 구역 단위로 화면 밖 객체를 제외한다.
- 변경된 계층 변환만 전파하고 월드 객체를 깊이순으로 정렬한다.
- 그림자 필터의 텍스처 샘플을 25회에서 9회로 줄인다.
- 성장 정보 저장과 로그 출력을 작업 스레드로 옮긴다.
- 후처리 패스는 유지하므로 Draw 호출 수 자체는 여전히 9회일 수 있다.

## 로그 사용
기본 실행은 약 1초 단위 JSONL 요약과 10프레임마다 GPU 샘플을 콘솔 및 실행 파일 옆 `GameData/Profiles`에 기록한다.
파일은 세션별 최대 8MiB × 4개로 순환한다. 이전 실행의 파일은 별도로 남는다.

- `--profile-per-frame`: 프레임별 Draw 횟수, 프레임 시간, FPS 및 CPU 세부 로그 추가.
- `--profile-gpu-every-frame`: GPU 계측을 매 프레임 수행.
- `--profile-no-gpu`: GPU 계측 제외.
- `--uncapped`: 16ms 타이머 대신 유휴 콜백으로 갱신. 드라이버의 수직동기화는 별개다.
- `--tutorial`: 기존 마을 튜토리얼과 함께 사용 가능.
- P 키로 후처리를 비교한다.

## AI 분석 기준
- `event`: session_start, graphics_info, profile_window, profile_frame, gpu_sample, session_end 등 기록 종류.
- CPU/background/GPU 통계의 `total_ms`, `mean_call_ms`, `max_call_ms`, `calls`는 해당 측정 구간의 합계·호출당 평균·최대·횟수다.
- CPU 구간은 중첩될 수 있으므로 모두 더해 전체 프레임 시간으로 해석하지 않는다.
- 창 단위 counters는 합계, gauges는 마지막 관측값이다. `draw_calls_mean`은 프레임당 평균이다.
- 프레임 시간은 화면 교환 이후 사이의 경과 시간이며 대기 시간을 포함한다. 최초 프레임 시간은 제외한다.
- FPS, 프레임 시간의 p95/p99/최대, 메모리, Draw 수, 업로드 바이트와 인스턴스 수를 함께 비교한다.
- SceneGraph 순회·정렬·컬링, 변환 변경, 충돌·시야 검사, 경로 탐색, AI·전투, 글꼴 생성, 캐시·파일 입출력·저장도 기록한다.
- GPU 결과는 준비됐을 때만 회수한다. `source_frame_id`와 `reported_at_frame_id`를 구분한다.
- `frame_timeline`은 CPU의 GPU 명령 공급 공백도 포함할 수 있어 순수 GPU 사용 시간으로 단정하지 않는다.
- GPU 샘플 수와 로그 누락·쓰기 실패 카운터를 확인한다. 로그 큐가 차면 메인 스레드를 막지 않고 기록을 버린다.
- 저장은 짧은 시간 내 요청을 합치며 정상 종료 시 완료를 기다린다. 강제 종료 시 대기 중 저장은 유실될 수 있다.
- 모델 표현을 수정하면 모델 및 모델 아틀라스 캐시 버전을 함께 갱신한다.

## 검증 범위
코드 서식과 프로젝트 XML 등록만 정적으로 확인했다. 빌드·실행·화면·성능 향상은 미검증이다.
같은 맵·시점·후처리·빌드 구성으로 비교하고, 모델 가장자리·그림자·가림 순서 및 저장 복원을 확인한다.
새로운 성능 민감 작업에는 `Profile::Scope`, 작업량에는 `Profile::Count`, 상태값에는 `Profile::Gauge`를 추가한다.
