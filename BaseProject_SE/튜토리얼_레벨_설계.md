# 튜토리얼 레벨: 마지막 모닥불

프로토타입 0.2 — 렌더링 개선·한글화·월드 확장

## 이번 변경

| 구분 | 이전 | 현재 코드 |
|---|---|---|
| 화면 | 단색 도형을 화면에 직접 출력 | HDR 장면 버퍼 → 블룸 → 색 보정·비네트·경계 완화 → UI |
| 그림자 | 오브젝트마다 단단한 타원 | 동일한 광원 방향의 투영 그림자 + 별도 마스크 블러 + 지면 합성 |
| 인물 | 즉시 그리는 단순 도형 | 6가지 외형 × 4방향 × 8프레임, 총 192개 생성 스프라이트 |
| 재질 | 평면 색상 | 월드 좌표에 고정된 풀·흙·석재, 목재와 초가지붕 절차적 셰이더 |
| 호수 | 타원과 단순 선 | 확대된 수심 층, 시간에 따른 파문·수면 반짝임·가장자리 물결 |
| 모닥불 | 단순 불꽃 | 다층 불꽃, HDR 발광, 블룸, 불티와 연기 |
| 언어 | 영문 비트맵 | 한글 대화·UI·창 제목, Windows 맑은 고딕 글리프 캐시 |
| NPC | 9명 | 18명: 마을 인물 16명과 정찰병·벌목꾼 |
| 맵 | 34 × 31 월드 단위 | 68 × 62 월드 단위, 총면적 정확히 4배 |
| 짐승 | 없음 | 사슴 6, 멧돼지 4, 늑대 4, 총 14마리 |

현재 스프라이트는 별도의 외부 이미지가 아니라 시작 시 GPU 아틀라스에 생성하는 도형 기반 이미지다. 투구·머리·얼굴·목·몸통·가죽 띠·망토·방패·검·팔·다리·장화를 구분하고 방향과 보행 프레임을 적용한다. 본편의 최종 아트 스타일이나 상용 리소스 채택을 확정한 것은 아니다.

그림자는 2.5D 지면에 투영하는 소프트 마스크이며, 3D 그림자 맵이나 실제 광선 추적은 아니다. 재질도 외부 사진 텍스처 대신 절차적 셰이더를 사용한다. 후처리의 경계 완화는 주변 픽셀 대비를 활용하는 간단한 필터다.

## 레벨 목적과 예상 시간

작은 마을에서 가족의 소식을 듣고 숲과 호숫가의 단서를 찾아 북쪽 고개로 출발한다. 확장된 외곽 숲·초원은 선택 탐험이며 기존 퀘스트 지점은 유지한다.

1. 장로 로나와 대화한다.
2. 붉은 길 표식을 따라 정찰병 에렌을 찾는다.
3. 호숫가의 부서진 수레에서 가족의 매듭을 조사한다.
4. 장로에게 생존 단서를 보고한다.
5. 북쪽 관문에서 출발해 튜토리얼을 완료한다.

주 동선은 2~4분, 5분 이내를 목표로 설계했다. 0.2 버전의 실제 시간은 아직 측정하지 않았다. 선택 탐험·추가 대화·짐승 관찰을 모두 하면 5분을 넘을 수 있으며 강제 시간 제한은 없다.

## 월드와 등장인물

이동 경계는 x ∈ [-34, 34], y ∈ [-34, 28]이다. 기존 경계 [-17,17] × [-17,14] 대비 각 길이가 두 배다. 집은 5채에서 9채로 늘렸고 중앙 광장은 거친 석재, 주변 마당과 길은 흙, 외곽은 풀·돌·침엽수로 구성한다. 집에는 돌기초, 목조 벽, 초가지붕, 장작과 항아리를 더했다.

마을 인물: 장로, 대장장이, 직조공, 목동, 사냥꾼, 요리사, 경비병, 어부, 목수, 방앗간지기, 가죽장이, 약초상, 상인, 석공, 견습생, 순찰병. 숲에는 정찰병과 벌목꾼이 있다. 모두 이름과 한글 대사가 있다. 주요 퀘스트 인물은 제자리를 유지하고 다른 인물은 가까운 범위에서 움직인다.

호수는 중심 (14,-4)에 배치한다. 렌더링 수면 반경은 월드 축 기준 7.4 × 9.2, 이동 차단은 캐릭터 여유를 포함해 7.65 × 9.45다. 단서는 기존 (5,-7)에 유지한다.

## 야생 짐승

- 사슴: 숲과 초원에 배회하며 플레이어가 가까워지면 달아난다.
- 멧돼지: 먹이를 찾듯 천천히 배회하고 너무 가까이 접근하면 거리를 벌린다.
- 늑대: 북서쪽 숲에서 자신의 서식지 주변을 배회하며 일정 거리까지 접근·경계한다.
- 짐승은 물·집·나무 밑동·맵 경계의 이동 제한을 따른다. 서식지에서 멀어지면 돌아온다.
- 가까운 짐승에 E로 관찰 설명을 볼 수 있다. 퀘스트 대상과 NPC 상호작용을 우선한다.
- 이번 버전에는 짐승과의 공격·피해·사냥·전리품 시스템을 추가하지 않았다.

## 조작

| 키 | 기능 |
|---|---|
| WASD | 화면 기준 이동 |
| E | 대화, 조사, 짐승 관찰, 관문 출발, 대화 다음 장 |
| Space | 열린 대화 다음 장 |
| Tab | 지도 전환 |
| H | 도움말 |
| P | 후처리 켜기/끄기 비교. 그림자와 재질은 유지 |
| Esc | 대화 닫기 또는 일시정지/재개 |
| Q | 일시정지 중 종료 |
| R | 완료 후 다시 시작 |

대화 중 플레이어와 짐승 이동을 멈춘다. 일시정지나 창 포커스 이탈 시 시간과 상태 갱신을 멈춘다. 재시작하면 NPC·짐승·퀘스트·타이머를 초기화한다.

## 코드와 자원

- Renderer.cpp / Renderer.h: 화면 배치, 머터리얼 셰이더, HDR 장면 FBO, 그림자 마스크, 블룸과 최종 합성.
- RendererAssets.cpp: Windows GDI를 이용한 UTF-8 한글 글리프 캐시와 캐릭터 스프라이트 아틀라스 생성.
- Tutorial.cpp / Tutorial.h: 퀘스트, 한글 대화와 UI, 이동, NPC 및 월드 데이터.
- TutorialWorld.cpp: 지형, 건물, 나무, 그림자, 불·물 효과, 짐승 표현과 행동.
- SimpleGame.cpp: OpenGL 초기화, 창 한글 제목, 입력 및 타이머.
- SimpleGame.vcxproj / filters: 추가 코드 등록, 모든 구성에 /utf-8 지정. 기존 gdi32.lib와 user32.lib 링크를 사용한다.

OpenGL 3.3과 기존 FreeGLUT/GLEW DLL이 필요하다. 새로운 다운로드나 외부 폰트·이미지 파일은 없다. 글꼴은 Windows 설치 글꼴을 사용한다. 셰이더와 캐릭터 생성 코드는 프로젝트에 포함되며, 기존 SolidRect 셰이더 파일은 보존하지만 사용하지 않는다.

## 직접 확인할 항목

1. 원하는 x86/x64, Debug/Release 구성으로 빌드한다. 추가 소스 2개와 /utf-8 설정이 반영되었는지 확인한다.
2. 창 제목·목표·도움말·18명 대화·관찰·완료 화면의 한글 깨짐과 줄 넘침을 확인한다.
3. P로 같은 장면의 후처리를 비교한다. UI는 후처리 유무와 무관하게 선명해야 한다.
4. 나무·집·캐릭터 그림자가 같은 방향으로 드리우며 캐릭터 위를 덮지 않는지 확인한다.
5. WASD 방향 변경과 걷기/정지 시 캐릭터 스프라이트를 확인한다.
6. 카메라 이동 중 지면 재질이 화면에 붙어서 미끄러지지 않는지 확인한다.
7. 호숫가 물결·반짝임, 모닥불의 발광·불티·연기를 확인한다.
8. 기존 영역 바깥의 숲과 남쪽 초원에 진입하고 짐승의 배회·회피·관찰을 확인한다.
9. 핵심 퀘스트를 다시 완료하고 시간을 측정한다. 재시작·일시정지·Alt-Tab·창 크기 변경도 확인한다.
10. 확대된 숲과 마을의 프레임률을 확인한다. 현재 CPU 쪽 화면 범위 검사를 적용했지만 실제 성능 수치는 측정하지 않았다.

이번 변경의 확인 범위는 정적 소스 검토, 프로젝트 XML 확인, 수량 및 경계 데이터 확인이다. 사용자 방침에 따라 Codex는 빌드와 게임 실행, 화면 캡처를 수행하지 않았다.
